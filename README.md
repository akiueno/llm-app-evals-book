## インストールガイド

第2部のハンズオンを始める前に、以下のソフトウェアをインストールしてください。

1. [Git](https://git-scm.com/install/)
2. [Docker Desktop](./docs/install-docker.md)
3. [Visual Studio Code](./docs/install-vscode.md)
4. [Visual Studio Codeの拡張機能「Dev Containers」](./docs/install-devcontainer.md)

## 第2部のハンズオンの構成

第2部のハンズオンで使用するソースコードは、以下の構成になっています。

| ディレクトリ                | 内容                                                                                 |
| --------------------------- | ------------------------------------------------------------------------------------ |
| [`starter/`](./starter)     | ハンズオン開始時点のコード（第7章完了状態）。第8章以降はここから書き加えていきます。 |
| [`chapter08/`](./chapter08) | 第8章で追加するファイル                                                              |
| [`chapter09/`](./chapter09) | 第9章で追加するファイル                                                              |
| [`chapter10/`](./chapter10) | 第10章で追加・修正するファイル                                                       |
| [`completed/`](./completed) | `starter/` に各章のoverlayを重ねた完了版（参考用）                                   |
